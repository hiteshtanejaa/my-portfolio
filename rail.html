26–30 RAILCARD UI

HTML CSS Canvas API UI Design No Frameworks

A pixel-perfect recreation of the UK 26–30 Railcard — built entirely in vanilla HTML, CSS and JavaScript with no external libraries. The goal was to match the physical card's feel as a pure frontend exercise.

The holographic logo badge is a pure CSS conic-gradient animation. The QR code is generated dynamically on a Canvas element with finder-pattern decorators. Everything — card layout, portrait frame, serial number, validity grid — is hand-coded from scratch.

Visual
Holographic badge — CSS conic-gradient + keyframe spin
Dynamic
QR code generated via Canvas API on load
Layout
CSS Grid — matches physical card proportions
Responsive
Full-width on mobile, card width on desktop
